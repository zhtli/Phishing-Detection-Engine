# `features/domain/ngram_tables/` — lexical n-gram frequency tables

Static n-gram frequency tables loaded by the domain lexical transformation
(`../transformations/lexical.py`) to score how "word-like" a domain name is.

| File | Built from |
|------|-----------|
| `ngram_freq.json` | Baseline English n-gram frequencies. |
| `ngram_freq_dga.json` | Domains generated by DGAs (malware domain-generation algorithms). |
| `ngram_freq_malware.json` | Known malware domains. |
| `ngram_freq_phishing.json` | Known phishing domains. |
